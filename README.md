# Link Click Fan Page

Página web fan dedicada a **Link Click (时光代理人)**, uno de mis primeros proyectos personales.

El sitio cuenta con varias páginas donde se puede encontrar información sobre la serie, sus personajes y plataformas, además de una galería de imágenes y un formulario para unirse al club de fans.

## Características

- Página principal con introducción y sinopsis.
- Video de la serie.
- Sección de personajes con tablas.
- Galería de imágenes con desplazamiento horizontal.
- Formulario interactivo para el club de fans.
- Diseño responsive para celulares y tablets.
- Uso de Flexbox y Grid.
- Efectos `hover` y estilos personalizados.

## Tecnologías utilizadas

- HTML5
- CSS3

Este proyecto representa una de mis primeras experiencias creando una página web completa con varias secciones y páginas conectadas entre sí.
